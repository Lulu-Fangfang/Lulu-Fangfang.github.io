# Lulu-Fangfang.github.io

路路与方方的恋爱小平台：核心分为日常美好、事务记录台账、沟通记录，并包含每日手账、心愿兑换和共同约定。网站无构建依赖，可直接部署到 GitHub Pages。

## Supabase 首次初始化

公开连接配置已经写在 `supabase-config.js`。其中的 publishable key 本来就用于浏览器，可以公开；不要把 `service_role`、secret key 或数据库密码写入仓库。

1. 打开 Supabase 项目，进入 `Authentication > Users`。
2. 点击 `Add user > Create new user`，创建并自动确认以下两个用户：
   - `fangfang@login.lulufangfang.me`，密码 `19991210`
   - `lulu@login.lulufangfang.me`，密码 `20000710`
3. 进入 `SQL Editor > New query`，粘贴并运行整个 `supabase-setup.sql`。
4. 确认结果显示成功后，进入 `Authentication > Providers > Email`，关闭公开注册（`Allow new users to sign up`）。邮箱密码登录需要保持开启。
5. 打开网站的“规则与数据”。状态应从“等待初始化”变为“云端等待登录”。如果页面已打开，请刷新一次。
6. 先在保存着原始记录的设备登录。若云端为空，网站会自动把该浏览器中的历史记录与图片迁移到 Supabase；完成后其他设备登录即可读取同一份数据。

初始化脚本会创建私有数据表、行级权限策略、Realtime 同步和私有 `moment-images` Storage bucket。脚本可重复执行；如果提示找不到两个用户，请先完成第 2 步，再重新运行整个脚本。

代码更新后可以重新运行整个 `supabase-setup.sql`。脚本会保留现有记录，并更新服务端函数与权限策略。

## 使用与权限

- 访客默认只读；点击右上角“身份登录”选择身份。
- 方方和路路小皇帝都能新增日常美好、每日手账、事务和沟通记录。
- 方方可以修改、删除自己创建的内容；路路小皇帝可以管理双方的全部内容，并负责复核、问题状态、规则和心愿兑换。
- 服务端会额外保护规则、心愿清单和兑换流水，方方账号不能绕过页面直接修改这些高权限数据。
- 登录后，文字与压缩图片会同步到两人的 Supabase 私有空间，并在当前浏览器保留缓存。每台电脑或手机都需要先选择身份登录，才能读取受 RLS 保护的云端数据。
- 刷新页面、重新进入或 30 分钟无操作都会退出身份并重新锁定，不持久保存 Supabase 登录会话。
- 云端未初始化或暂时不可用时，网站保留本机模式；文字使用 `localStorage`，图片使用 `IndexedDB`。

## 功能

- 本周期“已办”的事务自动换算心愿额度，并按兑换流水扣减可用余额。
- 心愿清单与兑换流水分离，同一心愿可以重复兑换、单独确认完成或撤销。
- 事务记录台账支持精确到分钟的计划时间、未办/进行中/已办状态、关键词搜索、本周期筛选、快速勾选和 CSV 导出。
- 日常美好记录支持每条最多 4 张自动压缩图片；每日手账支持按日期记录、完成和复核。
- 完整 JSON 备份包含设置、所有模块数据和本机图片，并兼容旧版数据自动迁移。
- 多设备同时修改采用版本检查；发生冲突时载入云端最新版，避免静默覆盖。

## 备份与安全

Supabase 是主要跨设备存储，本机缓存不是唯一备份。仍建议定期在“规则与数据”中导出完整 JSON 备份，尤其是在批量修改或清理浏览器数据之前。

RLS 限制只有两位家庭成员能读取数据和图片；数据库函数还会区分共同记录者与管理复核者。但是该站点不应保存身份证、银行卡、医疗资料等高敏感信息。若更换账号，应先更新 Auth 用户，再重新运行并检查成员关系和 RLS。
