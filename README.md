# Lulu-Fangfang.github.io

路路与方方的小站：包含沟通复盘、心愿兑换、周期进度和共同约定。

## 使用

- 这是一个无构建依赖的静态站点，可直接部署到 GitHub Pages。
- 访客默认只读；点击右上角“管理员登录”后可以新增、修改、删除记录和心愿。
- 初始管理员密码为 `Lulu-Fangfang-2026!`。登录后可在“设置”中修改。
- 数据默认保存在当前浏览器的 `localStorage` 中。换设备前，请在“设置”里导出 JSON 备份，再在新设备导入。

## 安全边界

当前仓库是 GitHub Pages 静态站点，管理员密码是前端本地解锁机制，不等同于服务器端身份认证。它适合夫妻双方共同使用的私密记录，不适合存放高敏感资料；如果需要真正的跨设备账号、云同步和服务端权限校验，需要接入带认证的后端服务。
