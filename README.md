# Lulu-Fangfang.github.io

路路与方方的小站：包含日常美好、每日手账、行为日志、问题沟通、心愿兑换和共同约定。

## 使用

- 这是一个无构建依赖的静态站点，可直接部署到 GitHub Pages。
- 访客默认只读；点击右上角“身份登录”后选择方方或路路小皇帝。
- 方方是记录者，初始密码为 `19991210`；负责日常美好、每日手账、行为日志和问题沟通的记录。
- 路路小皇帝是复核者，初始密码为 `20000710`；负责各模块复核、问题状态、规则和心愿兑换。
- 身份只保存在当前页面内存中。刷新页面、离开后重新进入或 30 分钟无操作都会重新锁定。
- 文字数据保存在当前浏览器的 `localStorage`，图片保存在当前浏览器的 `IndexedDB`。

## 功能

- 周期记录自动换算心愿额度，并按兑换流水扣减可用余额。
- 心愿清单与兑换流水分离，同一心愿可以重复兑换、单独确认完成或撤销。
- 复盘记录支持关键词搜索、确认状态筛选、本周期筛选和 CSV 导出。
- 日常美好记录支持每条最多 4 张自动压缩图片；每日手账支持按日期记录、完成和复核。
- 完整 JSON 备份包含设置、所有模块数据和本地图片，并兼容旧版数据自动迁移。
- 看板显示余额明细、近 7 天趋势、最近记录和心愿状态。

## 安全边界

当前仓库是 GitHub Pages 静态站点，它本身没有接收和保存上传文件的服务器接口。因此，网页中选择的图片只会保存在当前浏览器，清理浏览器数据后会丢失，也不会自动同步到手机或其他设备。换设备或清理缓存前，必须在“设置”中导出完整 JSON 备份，再在新设备导入。

前端密码是本地使用的轻量解锁机制，不等同于服务端身份认证，也不适合保护高敏感资料。若需要真正的跨设备图片存储、账号认证和云同步，需要接入 Supabase Storage、Cloudinary 等后端服务，并重新设计服务端权限规则。
